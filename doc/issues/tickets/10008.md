**Split from [#10002](10002.md), proposal 5**, which that ticket flagged as independent of the `tskip()` fix. Filed so it is not lost when #10002 closes.

**Symptom:** A test file that runs to completion having made zero assertions is reported as `✓ PASS`, indistinguishable from a file that asserted and passed. TestMe already counts assertions per file — the summary prints `Assertions: N/M passed` — so it has the number and does nothing with a zero.

**Why it matters:** a file that completes having asserted nothing is nearly always a gate that silently swallowed its own body: an early `return`, a conditional that never became true, an exception caught and discarded, or a helper that exits before the assertions. #10002's `tskip()` defect is one instance of that shape, and this heuristic would have caught the Appweb leak test independently — before `tskip` was ever called.

Now that #10002 is fixed, a deliberately skipped test reports `Skipped` and never reaches this check, so the remaining zero-assertion files are the accidental ones. That is what makes the heuristic worth having: after the skip protocol exists, zero assertions no longer has a legitimate meaning.

**Expected Behavior:**
- A test file that exits 0 with zero assertions is reported distinctly from one that asserted and passed — at minimum a warning beside the result, so the headline count cannot silently include it.
- A skipped test (exit `TM_EXIT_SKIP`) is exempt; it never ran by design.
- Decide whether the warning is advisory or a failure, and whether it is opt-in by configuration. Some legitimate tests assert nothing and rely on their exit status alone (a shell test that runs a command and lets a non-zero status fail it), so defaulting to a failure would break them. Advisory by default with a configuration key to escalate is the likely shape.

**Files to Investigate:**
- `src/handlers/base.ts` — `createTestResult()`, which already calls `countAssertions()` and holds the precedent for deriving status from output
- `src/utils/assertion-counter.ts` — the counter itself
- `src/reporter.ts` — where the warning would be shown

**Verification Criteria:**
1. A test file that exits 0 having printed no assertion markers is reported distinctly from a passing one.
2. A file that skipped itself is not warned about.
3. A shell or Python test that legitimately asserts nothing and relies on its exit status can silence the warning through configuration.
4. `tm` passes in this repo.
